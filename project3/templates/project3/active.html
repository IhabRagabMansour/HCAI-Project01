Active Learning for Expert Discovery

From Task 4 the expert's labels are no longer available during training. The classifier is already trained, but we must actively query the expert on selected pool examples to learn P(expert correct | x) — the model that drives the deferral decision. Each query is expensive, so the goal is to reach good team performance with as few expert queries as possible.
