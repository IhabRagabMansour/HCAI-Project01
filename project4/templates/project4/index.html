Preference Elicitation

A new user of a movie recommender has no rating history — the cold-start problem. This project designs a user study comparing two ways of learning a new user's taste from a small number of interactions:

  • Design 1 — Pairwise: repeatedly show two movies and ask which one the participant would rather watch.
  • Design 2 — Ranking: show ten movies and ask the participant to rank them from most to least preferred.

Each movie is described by a feature vector x, and each user by a latent preference vector w, with utility U(x) = wTx. The elicitation process estimates w from the participant's responses: a Bradley–Terry model for pairwise choices, extended to a Plackett–Luce model for full rankings.
